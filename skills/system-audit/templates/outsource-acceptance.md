# 外包验收审查表（outsource-acceptance）

> 外包项目交付验收用（技术方开发完成后的验收核查）。重点：功能完成度（防超范围开发）、交付物完整性、文档、代码质量、许可证、知识产权归属、数据合规。
> **交付物边界先确认**：合同/需求文档里约定的交付范围（含什么/不含什么），验收时逐项对照。
> **系统类型声明**（优先从 feature-spec 读取）：☐ Web 应用 　☐ 小程序 　☐ 桌面端 　☐ 服务端 API 　☐ 混合
> 状态列：✅ 通过（1 分）/ ⚠️ 待改进（0.5 分）/ ❌ 缺失（0 分）/ ➖ 不适用（不计分）。证据列必须填。
