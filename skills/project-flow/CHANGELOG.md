# Project Flow · 迭代记录

> 规则：每次迭代先在此登记（版本号、日期、改了什么、为什么改），再改 SKILL.md。

## v1.1.0 — 2026-09-01（公开版语言机制）

- 新增「语言」章节：默认英文，首次运行读 `~/.claude/skill-preferences.json`，无配置则以英文询问用户常用语言并写入；之后所有输出用偏好语言
- 偏好文件为全部 skill 共享（问一次处处生效）；仓库不携带配置文件，安装者首次运行自行询问
- 注明：外部依赖 grilling 的输出语言不受本项目偏好控制

## v1.0.0 — 2026-09-01（基线）

**创建**：project-flow 编排 skill，项目生命周期指挥器。

- 定位：阿楼「一个入口」需求——grilling（拷问）、feature-spec（功能清单）、system-audit（审查）三个独立 skill 的组合层，不复制业务逻辑，只做状态探测 + 路由 + 产物衔接
- 关键设计：**不预设新项目**——按「项目进度」路由（想法/规划/开发/上线/运营/外包），任何进度说一句话即可进入
- 流程：确认项目与意图 → 只读探测（spec 有无/代码有无/审查档案）→ 路由表（9 条路径）→ 调 Skill 工具执行，每步完成问用户是否继续
- 触发词：立项、新需求、接下来做什么、走流程、梳理项目、查进度、体检、验收等
- 与 v1.1 system-audit 的衔接：spec 落盘 docs/feature-spec.md 后，审查自动读取做完成度对照
